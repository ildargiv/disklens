## Зачем

Когда диск заполнен, главный вопрос не «что большое?», а «что можно удалить, сколько это
*на самом деле* освободит и не сломается ли что-нибудь?». Большинство анализаторов отвечают
только на первую половину, а на Windows часто и её считают неверно: junction-папки
учитываются дважды, `WinSxS` из-за жёстких ссылок выглядит вдвое больше, облачные
файлы OneDrive будто бы занимают место, которого не занимают.

DiskLens построен вокруг второй половины:

- **Показывает, сколько реально освободится.** Размер «на диске» с точностью до кластера
  и с учётом NTFS-сжатия, жёсткие ссылки считаются один раз, junction и симлинки не обходятся.
- **Никогда не удаляет безвозвратно по ошибке.** Удаление — только в Корзину и только после
  подтверждения. Если объект не помещается в Корзину, Windows спросит, а не удалит молча.
- **Объясняет, что это за папка.** Классификация помечает кэши и артефакты сборки как
  `safe`, сомнительное — `review_first`, системные данные (WinSxS, Installer, диски Docker/WSL)
  — `keep` с подсказкой, как освободить место правильно.
- **Быстрый.** Параллельный сканер читает каталоги пакетами прямо из NTFS — сотни тысяч
  файлов примерно за секунду.
- **Работает с ИИ-агентами.** `disklens mcp` позволяет Claude, Cursor, OpenCode и др.
  измерять, классифицировать и (с подтверждением) отправлять в Корзину.

## Установка

1. Откройте **[последний релиз](https://github.com/ildargiv/disklens/releases/latest)**.
2. Скачайте **`DiskLens-Setup-<версия>.exe`** и запустите.

Установщик не требует прав администратора, содержит сборки для x64 и ARM64, по желанию
добавляет `disklens` в `PATH` и пункт **«Анализировать в DiskLens»** в контекстное меню
папок и дисков Проводника, создаёт ярлык в меню «Пуск» и полностью удаляется через
«Приложения». Интерфейс установщика — на русском и английском.

**Портативная версия:** скачайте `disklens-windows-amd64.exe` (или `-arm64.exe`),
переименуйте в `disklens.exe` — это один самодостаточный файл. Контрольные суммы — в `SHA256SUMS.txt`.

## Быстрый старт

```powershell
disklens                 # текущая папка
disklens C:\Users\me     # конкретная папка
disklens D:\             # весь диск
```

Или правый клик по папке в Проводнике → **Анализировать в DiskLens**.

Во время сканирования виден прогресс; <kbd>Esc</kbd> останавливает скан и открывает то,
что уже найдено.

| Клавиша | Действие |
|---|---|
| <kbd>↑</kbd><kbd>↓</kbd> / <kbd>j</kbd><kbd>k</kbd> | перемещение |
| <kbd>Enter</kbd> / <kbd>→</kbd> | открыть папку |
| <kbd>Esc</kbd> / <kbd>←</kbd> | назад |
| <kbd>/</kbd> | фильтр по имени |
| <kbd>s</kbd> <kbd>n</kbd> <kbd>c</kbd> | сортировка: размер, имя, число файлов |
| <kbd>a</kbd> | размер на диске ↔ логический размер |
| <kbd>d</kbd> / <kbd>Delete</kbd> | в **Корзину** (с подтверждением, можно восстановить) |
| <kbd>x</kbd> | очистить Корзину (с подтверждением, безвозвратно) |
| <kbd>r</kbd> | пересканировать текущую папку |
| <kbd>o</kbd> | показать в Проводнике |
| <kbd>?</kbd> | справка |
| <kbd>q</kbd> | выход |

## Командная строка

| Флаг | Значение |
|---|---|
| `--depth N` | сколько уровней показать (`0` — всё) |
| `--top N` | только N крупнейших на уровне |
| `--files` | показывать и файлы |
| `--min-size 1G` | скрыть всё меньше указанного размера |
| `--sort size\|name\|files` | порядок |
| `--exclude ШАБЛОН` | пропускать совпадающие имена (можно несколько раз) |
| `--json` | машиночитаемый вывод |
| `--apparent` | логический размер вместо размера на диске |
| `--strict` | код выхода `2`, если часть папок недоступна |
| `-o файл` / `-f файл` | экспорт / импорт в формате ncdu JSON |

```powershell
disklens --json --files --depth 0 --min-size 1G D:\ > big.json
disklens --no-tui --exclude node_modules --exclude .git C:\src
```

## ИИ-агенты (MCP)

```json
{ "mcpServers": { "disklens": { "command": "disklens", "args": ["mcp"] } } }
```

Инструменты: `scan`, `top`, `children`, `du`, `largest_files`, `classify`, `duplicates`,
`recycle_bin`, `delete_to_recycle` (только с `confirm: true`), `empty_recycle_bin`
(только по явной просьбе пользователя). Каждый инструмент сам сканирует папку при
необходимости и сообщает возраст данных. Подробности — в [AGENTS.md](AGENTS.md).

## Как DiskLens считает

| Ситуация | DiskLens |
|---|---|
| Junction, точки монтирования, симлинки на папки | не обходятся и не считаются файлами |
| Жёсткие ссылки (`WinSxS` ↔ `System32`) | байты учитываются **один раз** |
| Сжатые и разреженные файлы NTFS | реальный занятый размер |
| Облачные файлы OneDrive | столько, сколько они реально занимают локально |
| Нет доступа (`ACCESS_DENIED`) | скан продолжается, итог помечается как неполный |
| Пути длиннее 260 символов, кириллица, эмодзи | поддерживаются |
